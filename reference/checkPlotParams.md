# Check plot params

Checkmate extension for the output of
[`params_plots()`](https://gregorlueg.github.io/bixverse.plots/reference/params_plots.md).

## Usage

``` r
checkPlotParams(x)
```

## Arguments

- x:

  The object to check.

## Value

`TRUE` if the check was successful, otherwise a checkmate-style error
string.
