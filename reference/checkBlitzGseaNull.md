# Check a blitzGSEA null model

Checkmate extension for checking a `BlitzGseaNull` object, i.e. the
output of
[`bixverse::blitzgsea_calibrate()`](https://gregorlueg.github.io/bixverse/reference/blitzgsea_calibrate.html).

## Usage

``` r
checkBlitzGseaNull(x)
```

## Arguments

- x:

  The object to check/assert.

## Value

`TRUE` if the check was successful, otherwise an error message.
